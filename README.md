# Work Profile

## Boutique Shopping Website Development
- **Technologies Used**: React.js, Express.js, HTML, CSS, MySQL, Webpack  
- **Tools Used**: GitHub, Heroku  
- **Project Overview**:  
  This project provides an **elegant and intuitive shopping platform**, allowing users to **browse product catalogs, add items to the shopping cart, and track order status**. The platform is optimized for e-commerce, prioritizing **a seamless and fast shopping experience**.  
- **Technical Challenges & Solutions**:  
  - **Image Processing**: Utilized the **Canvas API** for image handling to **reduce page load times** and ensure **fast rendering across devices**.  
  - **Responsive Web Design (RWD)**: Implemented **a fully responsive layout**, ensuring **a consistent user experience across different screen sizes**.  
  - **Logistics Integration**: Integrated the **7-Eleven logistics API**, allowing users to **track orders and select various shipping options**.  
  - **Authentication System**: Implemented **JWT authentication**, using `httpOnly` cookies to **determine user permissions for modifying platform functionalities**.  
- **Project Link**: [Boutique Shopping Website](https://londoner-store-387fd8edcda3.herokuapp.com/)
